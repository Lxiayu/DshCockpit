# v0.3.0 真机测试 Checklist

> 执行顺序建议：先推 master（不打 tag）→ Actions 页手动触发 release-win / release-mac（workflow_dispatch）→ 下载产物按本清单测试 → 全部 P0 通过后打 tag `v0.3.0` 正式发版。
> 标注 🤖 的项已有自动化覆盖（E2E 门禁/单测），人手只需确认；其余必须人工执行。

---

## 一、macOS（arm64，本机）

### A. 安装与启动
- [ ] 🤖 A2 门禁：CI 构建步骤含 E2E smoke（boot→URL→health 200→SIGTERM 干净退出）且为绿
- [ ] P0 双击 `DshCockpit.app` 首次打开：右键 → 打开 绕过 Gatekeeper；loading splash 出现 → 主窗口打开 → Cockpit 侧栏出现
- [ ] P0 `~/Library/Application Support/dsh-cockpit/diagnostics/boot-timing.json` 存在，数值合理（urlMs/healthyMs < 5000）
- [ ] P1 日志含 `[perf] main window paintable in Xms`（A3 打点生效）
- [ ] P2 挂机 2 分钟以上：无任何错误弹窗（覆盖 60s 托盘定时器、4h 轮询等慢触发路径）

### B. 核心链路
- [ ] P0 发起一次真实对话（需 API Key）：流式响应、会话落盘、退出备份日志出现
- [ ] P0 退出（托盘 → 退出）：**无任何错误弹窗**（回归：isQuitting / tray is not defined）→ 进程干净退出
- [ ] P1 关闭主窗口 → 隐藏到托盘；托盘点击重新打开
- [ ] P1 Quick Ask 全局快捷键呼出 → 输入提交 → 关闭
- [ ] P1 会话搜索（Cmd+K）打开 → 搜索 → 关闭
- [ ] P1 Cockpit 侧栏：拖动、主窗口最小化时隐藏、恢复时重现

### C. v0.3.0 新功能
- [ ] P0 设置 → 通知中心：页面打开、历史列表有数据（或空态文案）、规则开关保存后重开设置页仍保持
- [ ] P0 设置 → 成本：缓存经济学卡片显示金额与命中率（需有含缓存读的会话数据）；按天条形图渲染
- [ ] P0 设置 → 任务与自动化 → Agent 周报卡片：「立即生成本周卡片」→ 提示 PNG 路径 → 打开报告目录确认 PNG 存在且内容正确（双语、无绝对路径泄露）
- [ ] P0 设置 → 关于 → 启动自检：显示上次自检结果；「立即重检」刷新；如有可修复项「一键修复」后重新自检通过
- [ ] P1 设置 → 更新 → 上游兼容状态：显示 `✅ 已验证兼容（0.1.1-rc.2）`
- [ ] P1 自检完成时若 splash 仍在（慢启动模拟），文案更新为「启动自检通过 x/7 项」（D6）

### D. 外观与语言
- [ ] P1 切换语言 zh ↔ en：通知中心/缓存看板/周报卡片/启动自检四个新 UI 全部跟随，无中英混排残留
- [ ] P2 深浅主题切换：新 UI 元素（大数字、条形图、徽章）颜色正确

### E. slim 轨道（可选）
- [ ] P2 `DshCockpit-*-slim-mac-arm64.zip`：解压启动 → 出现引导安装流程（可取消，不必真装完）

## 二、Windows（x64）

### A. NSIS 安装器（主推轨道）
- [ ] P0 双击 `DshCockpit-0.3.0-win-x64.exe`：无 UAC 弹窗（per-user）→ 一键安装 → 自动启动
- [ ] P0 安装位置为 `%LocalAppData%\Programs\DshCockpit`；开始菜单快捷方式存在
- [ ] P0 `resources/app-update.yml` 存在且 owner 为 `Lxiayu`（非 local）🤖 E2E 门禁已断言，人工复核
- [ ] P0 启动：内置运行时冷启动（AV 扫描可能 10-30s）→ loading → 主窗口；**无「准备中」无限转圈**（回归）
- [ ] P0 退出（托盘 → 退出）：**无 isQuitting / tray is not defined 弹窗**（回归）→ 干净退出
- [ ] P0 卸载（设置 → 应用）：安装目录删除；`%APPDATA%\dsh-cockpit` **保留**（数据不丢）
- [ ] P1 覆盖安装 v0.3.0 exe：数据延续、无配置丢失
- [ ] P1 Defender/SmartScreen 行为记录（未签名预期有"未知发布者"警告——记录文案供 README 完善）

### B. 便携 zip（逃生轨道）
- [ ] P0 解压 `DshCockpit-0.3.0-win-x64.zip` → 双击 `DshCockpit.exe` → 正常启动（记录解压耗时，应明显优于 0.2.9）
- [ ] P1 删除解压目录：记录耗时（应明显优于 0.2.9，文件数 -55%）
- [ ] P2 `SHA256SUMS-win.txt` 校验通过：`certutil -hashfile <file> SHA256` 对照

### C. slim 轨道
- [ ] P1 解压 `DshCockpit-0.3.0-slim-win-x64.zip` → 启动 → 出现引导安装（首次运行安装运行时）流程

### D. 自动更新链路（macOS = 实验特性，见 §11 H-mac-sign）
- [ ] P1 macOS 更新演练（v0.3.1 出包后）：装 v0.3.0 → 用 v0.3.1 zip + latest-mac.yml 起本地 feed → 实测 Squirrel.Mac 对 ad-hoc 签名的替换行为 → 通过则 mac 自动更新转正，失败则 README 明确"mac 手动下载"

### D. 自动更新链路（Windows）
- [ ] P0 启动后日志含 `[shell] updater initialized`（设置 → 通用 开启"自动检查壳更新"）
- [ ] P0 启动无 updater 相关错误弹窗（v0.3.0 的 feed 已指向真实仓库；若 v0.2.9 升级用户则其旧 feed 仍指 local，属已知限制）
- [ ] P1 待 v0.3.1 发布后：应用内出现更新提示 → 差分下载（MB 级）→ 退出自动安装

### E. 核心链路（同 macOS B 组）
- [ ] P0 真实对话一次
- [ ] P0 通知中心 / 缓存看板 / 周报生成 / 启动自检 / 兼容状态 五个新 UI 各打开一次并操作
- [ ] P1 插件市场安装一个插件（pnpm 跟随逻辑；若 profile 由其他 major 创建应有可读指引而非裸报错）
- [ ] P2 挂机 2 分钟无错误弹窗
