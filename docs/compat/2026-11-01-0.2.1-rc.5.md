### 关键确认 1：AGENTS.md 预算语义

0.2.1 的 `dsh-agent-instructions` 里：

```js
DEFAULT_PROJECT_ROOT_MARKERS = [".git"];        // 未变
DEFAULT_MAX_SOURCE_BYTES = 1048576;             // 未变（1 MiB）
```

且新增了**项目级与全局级分别计算 maxBytes 预算**
（修复"项目指令挤掉全局指令"）。

**我们的 `brief-sync.js` 用的正是 `.git` 判定 + 1 MiB 上限 —— 语义完全一致，无需改动。**

### 关键确认 2：`agentTeam` 仍未进稳定 API

在 0.2.1 的 `dsh-api-session-controller/lib/types/` 里
**`agentTeam` 出现 0 次**（0.1.5 也是 0 次）。

这印证了 GPT 的判断，也印证了我们 ADR-0002 的谨慎：
**Team 投影仍然不是稳定公开 API。**

### 关键确认 3：新增的 `session/projections`

0.2.1 新增端点（0.1.5 没有）：

```
session/create  session/list   session/page    session/prompt
session/follow  session/control session/cancel session/fork
session/rename  session/search  session/attachment
session/projections              ← 新增：读事件投影
```

`session/projections` 对应官方"Session API 新增独立接口，可读取事件投影数据"。
**这是后续可用的新能力**（我们目前用 page 轮询）。

## 回滚方案

`runtime-state.json` 保留 `previousVersion: 0.1.5-rc.2`，
且该版本仍在 `installed` 列表里（未被 GC）。
`manager.activate('0.1.5-rc.2')` 可一键回退。
DSH_HOME 快照：`snapshots/pre-0.1.5-rc.2-2026-11-01T19-08-55-934Z`。

## 顺带修的两处

1. **日志可读性**：`sessionId.slice(0,8)` 对 `session-<uuid>` 恰好只截到
   `"session-"`，所有会话在日志里长得一样。改为 `shortSessionId()` 取 uuid 前 8 位。
2. **验收探针过时断言**：dock 验收脚本仍在量 `#list` 宽度，
   而上一轮已把它 `display:none`。改为量 picker。
