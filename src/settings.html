手机远程

在手机浏览器中安全使用本机会话

开启后走明文 HTTP：微信、抖音内置浏览器可直接打开链接；关闭则恢复自签名 HTTPS（系统浏览器需点「继续访问」）。局域网内明文传输，请勿在公共网络开启。
手机与本机连同一 Wi-Fi；开关与端口改动即存即生效，再把下方配对链接发到手机、用浏览器打开，之后可完整使用会话、审批、提问
安全说明：默认开启「微信/抖音打开兼容模式」时网关走明文 HTTP，配对码与长期令牌在局域网内明文传输（微信、抖音内置浏览器无法打开自签名 HTTPS，故提供此模式）；关闭兼容模式后为自签名 HTTPS，手机首次访问会提示「不受信任」，系统浏览器选择继续访问即可。配对码 10 分钟内一次性有效；长期令牌经系统加密存储、不进入设置与备份。运行时本身仍只监听 127.0.0.1，局域网只能到达此网关。请勿在公共网络下开启。

隐私与安全

隐私声明
本应用完全在本地运行。我们不会收集、上传或存储您的任何个人信息、API Key、会话内容或用量数据；所有数据仅保存在本机。仅在以下情况访问网络：更新检查（npm registry / GitHub Releases）、插件市场列表（GitHub）、运行时下载（npm registry）。费用估算基于您自行配置的价格参数，不构成计费依据。
安全说明：会话备份只包含会话记录与 settings.yaml，不包含 API 凭据（凭据仍在 DSH_HOME 的 .credentials.yaml，系统钥匙串集成规划中）；运行时下载全程校验完整性；harness 自带的文件沙箱与审批机制不受桌面化影响。
