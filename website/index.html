⚠️

macOS 提示「已损坏 / 无法验证开发者」？正常现象。
当前安装包尚未签名公证（暂无 Apple Developer 证书），这是 Gatekeeper 的正常拦截，应用本身没坏。最快放行方式——终端一行： xattr -dr com.apple.quarantine /Applications/DshCockpit.app
放行一次后即可永久正常启动；接入签名公证后此提示会消失。

从源码运行（开发者）： git clone https://github.com/Lxiayu/DshCockpit.git npm install && npm start · 需 Node.js ≥ 22

常见问题

DshCockpit 收费吗？
完全免费，MIT 开源。全部代码在 GitHub 公开，可审计、可自建、可二开。
我的数据安全吗？
完全本地运行：不收集、不上传、不存储你的个人信息、API Key、会话内容与用量数据。备份刻意不含 API 凭据（防明文密钥扩散），运行时下载全程 sha512 校验，harness 的文件沙箱与审批机制原样保留。
需要预装 Node.js 或 dsh 吗？
不需要。官方安装包内置运行时，双击即用、无需联网下载。从源码运行才需要 Node.js ≥ 22（本机未装 dsh 时首次启动会自动下载）。
macOS 提示应用「已损坏」？
安装包尚未公证，Gatekeeper 会拦截。在终端执行一次 xattr -dr com.apple.quarantine /Applications/DshCockpit.app 即可正常启动；接入签名公证后此提示会消失。
更新是怎么工作的？
双层解耦：壳自身启动时 + 每 4 小时自动检查（带更新说明对话框）；运行时走更新管道——冒烟测试守卫确保坏版本绝不激活，一键回滚到上一版本。
